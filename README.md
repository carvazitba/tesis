# tesis
repo para la tesis de la Maestria en Ciencia de Datos

## 📁 Organización de Carpetas

### `data/`
Contiene todos los datasets utilizados en el proyecto, organizados según  nivel de procesamiento:

- `raw/`  
  Datos originales sin modificaciones.  

- `processed/`  
  Datos limpios y transformados listos para análisis y modelado, no serán volcados en la tesis, sino que serán procesados posteriormente.  


---

### `src/`
Contiene el código del proyecto.

---

### `outputs/`
Almacena todos los resultados generados automáticamente por los scripts, aquellos que serán volcados en la tesis.

---

## 📄 Archivos en el raíz


- `libs.txt`  
  Lista de librerías necesarias para ejecutar el proyecto.  
  Puede instalarse con:  
  pip install -r libs.txt
